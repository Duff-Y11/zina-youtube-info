Privacy Policy

Effective October 4, 2026 · Zina YouTube

Zina YouTube is operated by Duff for personal management of the Zina channel. This policy describes the local authorization setup and the intended owner-controlled automation workflow. Public registration is not offered.

Information accessed and used

The tool uses YouTube API Services. With the owner's Google OAuth authorization, it can access channel identifiers, channel names and related channel information, and video identifiers and metadata needed for requested management actions. When the owner requests an upload, it processes the video file and metadata the owner supplies.

OAuth access tokens and refresh tokens allow the tool to carry out authorized tasks without asking the owner to sign in every time. Google account passwords are never requested or stored by this tool. The initial authorization test reads basic channel information; upload automation is a subsequent configuration step.

Storage and access

During setup, credentials and a limited channel-verification result are stored in access-restricted files on the owner's computer. If cloud automation is enabled, credentials must be transferred to private secret storage in the owner's cloud environment. Credentials and private API data are not published to this website or its public source repository.

Authorized data is used only to operate, verify and troubleshoot the owner's requested channel workflow. Only the owner and expressly authorized operators or service providers may process that data for these purposes.

Service providers and sharing

Google receives authorization requests and YouTube API requests. If the owner enables a cloud workflow, that hosting or agent provider processes the information needed to execute the workflow. This may include OpenAI's Codex environment when chosen by the owner. Credentials must not be included in chat messages or public logs. Channel data is not sold or used for advertising.

This informational website is hosted by GitHub Pages. GitHub may collect technical request information such as IP addresses for hosting and security, as explained in the GitHub Privacy Statement. The site adds no analytics, advertisements, cookies, embedded media or tracking scripts.

Retention and deletion

Credentials are retained while the owner keeps the integration enabled. Channel verification information is retained only as needed for setup and troubleshooting. Stored API metadata must be refreshed or deleted within 30 days; cloud automation must implement this retention rule before ongoing storage is enabled.

To disconnect, revoke access using Google's third-party access settings. To request removal of locally or cloud-stored credentials and API data, contact zina.echo.verse@gmail.com. The operator will stop the integration and delete the relevant stored authorization and API data within seven days of receiving a deletion or disconnection request. Deleting the tool's stored data does not delete videos already uploaded to YouTube.

Your choices

The owner chooses the Google account and YouTube channel and approves the requested permissions on Google's consent screen. The owner controls requested uploads, metadata changes and publication settings. New uses of data beyond this policy require an updated disclosure and consent.

Google and YouTube policies

See the Google Privacy Policy and YouTube Terms of Service. Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including applicable Limited Use requirements.

Contact and updates

For privacy questions or deletion requests, contact zina.echo.verse@gmail.com. Material changes will be reflected on this page with an updated effective date.
