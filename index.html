Zina YouTube is a personal automation tool for the owner of the Zina YouTube channel. It is being configured to support the owner's channel workflow through the YouTube Data API.

What the tool is for

The intended workflow includes reading the authorized channel's basic information, uploading owner-provided videos, and updating video titles, descriptions and visibility when the owner requests those actions. The initial setup verifies authorization by reading basic channel information.

Access stays with the owner

This is an owner-operated tool, not a public sign-up service. Access is granted through Google's OAuth consent screen. The owner selects the account and channel and may revoke access at any time. The tool does not request or store a Google password.

This website provides information only. It does not accept credentials or run the channel-management workflow.

Privacy and terms

Read the Privacy Policy before authorizing the tool. Zina YouTube uses YouTube API Services. By using the tool, you agree to be bound by the YouTube Terms of Service. Google processes data under its Privacy Policy.
